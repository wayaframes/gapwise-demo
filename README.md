# Gapwise landing page (simulated example)

Gapwise is not a real product. This is the landing page built in a simulated first round of the Waya Experiment Platform skills, with tagged links (UTM-PLAN.md) and a design based on researched patterns (DESIGN.md). Nothing here takes bookings, payments or data.

## The Round 1 record (branch `round-1-record`)

- `docs/`: the sources of the Ikigai, business case, mission and values and interview questions documents (the working copies live in the founder's Google Drive).
- `run/`: the saved record after each of the four skills (Define, Build, Track, Analyze), the sheet changes each one returned, a plain-English report, and the links the run used.

Everything here is invented. Tickets for this product are in this repo's Issues and its own board; they are never written anywhere else.
